# LinkedIn Outreach Messages

Rules specific to first-touch LinkedIn outreach messages. These sit on top of the universal rules in [Communication Style](communication-style.md) and [Voice and Tone](voice-and-tone.md).

## Voice

Write as a technical peer and industry expert, not a vendor.

1. Reference AI as a point of shared interest, not a pitch.
2. Minimize jargon. Use concrete terms tied to the account (e.g., "basis risk," "45Z," "carbon-intensity data") over generic buzzwords (e.g., "digital transformation," "synergies," "leveraging AI") unless the contact's own role uses that language naturally.

## Structure

1. No lists of 3+ items strung together - see the Overloaded Enumeration rule in [Voice and Tone](voice-and-tone.md).
2. Maximum 2 tight sentences before the signature.
3. Never open with a vague observational phrase. Banned openers include "I've been following," "I've been looking at," "I am reaching out," and similar. Always lead with the partnership line instead.
4. "If you are so inclined" (or "if you're so inclined") is an acceptable soft close.

## Signature

Every message ends with this exact 3-line signature. Keep the URL as plain text since LinkedIn does not render markdown links.

```
Feel free to find a time to chat or reach out: https://calendar.app.google/TXDQy7u6hPSrUMhX7
Mara
712-898-2341
```

1. Sign only as "Mara," never "Mara Jorgensen."
2. This signature is mandatory with no exceptions.

## First-Touch Message Format

Use this format for first-touch LinkedIn messages to new contacts.

1. **Character limit** - 300 characters total (body + signature, including line breaks) is a hard cap. The signature is 110 characters, so keep the body to 190 characters or less (170 or less to draft toward 280-290 total). Count the full message before finalizing. If over 300, cut the body, not the signature.
2. **Opening line** - Lead straight with "I partner with The Vessel Group on [specific work area tied to this account]." or "I am partnering with The Vessel Group on [work area]." No throat-clearing opener.
3. **Comparing-notes line** - One sentence comparing notes on the specific gap for this account, e.g., "I'd be happy to compare notes on [specific pain point] at [Company] if you're so inclined."
4. **Signature** - The 3-line block above, exactly as written.
